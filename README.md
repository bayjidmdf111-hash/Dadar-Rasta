# 🛺 দাদার রাস্তা (Dadar Rasta) - ৩ডি অটো-রিকশা গেম
> **রাস্তা কি দাদার পাইছেন?!** | 3D Bangladeshi Rickshaw Traffic Racing Web Game

**দাদার রাস্তা (Dadar Rasta)** একটি হাই-পারফরম্যান্স, মোবাইল-ফার্স্ট ৩ডি বাংলাদেশি ব্রাউজার গেম। **Three.js**, **React**, এবং **Web Audio API** দিয়ে তৈরি। কোনো অ্যাপ ইনস্টলেশন ছাড়াই সরাসরি গুগল ক্রোমে (Android 8.1+ ও ডেক্সটপে) চলে।

---

## 🎮 গেমের বৈশিষ্ট্য (Features)
- **দেশি ব্যাটারি চালিত অটো-রিকশা (Tomtom / Easy Bike / Mishuk)**: ডানে-বামে কাটার সময় আসল রিকশার মতো বডি টিল্ট ও রোল ফিজিক্স।
- **ঢাকার রাজপথের ট্রাফিক ও অবস্ট্যাকল**:
  - ছাদে স্যুটকেস ও বস্তা বোঝাই মুরগির খাঁচা লোকাল বাস ("মিরপুর সুপার লিংক", "বিকল্প সার্ভিস")।
  - খাঁটি রিকশা আর্ট আঁকা হুড ওয়ালা সাইকেল রিকশা।
  - লোহার খাঁচাযুক্ত সবুজ সিএনজি বেবি ট্যাক্সি।
  - ডিভাইডার বা রাস্তার ওপর বসে থাকা নিরীহ গরু ও ছাগল।
  - ওয়াসা-র খোঁড়াখুঁড়ি ও উন্মুক্ত ম্যানহোল।
  - কেটলি ও সিলিন্ডার ওয়ালা চায়ের টং দোকান ("করিম টি স্টল")।
  - মাথার ওপর এলোমেলো তারের জটলা ও হাস্যকৌতুকপূর্ণ বিলবোর্ড ("খাঁটি সরিষার তেল", "কাচ্চি বিরিয়ানি", "দাদার রাস্তা")।
- **মোবাইল ও পিসির কন্ট্রোল**:
  - **মোবাইল টাচ বাটন**: বড় ও রেসপনসিভ বামে (◀), ডানে (▶), ব্রেক (🛑), গতি/গ্যাস (⚡) এবং মিউজিক্যাল হর্ন (📢)।
  - **পিসি কীবোর্ড**: `A`/`D` বা Arrow keys দিয়ে ঘোরান, `W` গতি, `S` বা `Space` ব্রেক, `H` বা `Shift`/`Enter` হর্ন, `P` পজ।
- **১০০% প্রসিডিউরাল সাউন্ড (কোনো এক্সটার্নাল অডিও ফাইল নেই)**:
  - স্পিডের সাথে ফ্রিকোয়েন্সি ওঠা-নামা করা ইলেকট্রিক মোটরের ভনভন আওয়াজ।
  - ঢাকাইয়া ইলেকট্রিক মিউজিক্যাল হর্ন ("প্যাঁ-প্যাঁ-প্যাঁ!")।
  - লোকাল বাসের বিকট এয়ার হর্ন ("ভোঁওওন!")।
  - ব্রেকের ঘষা, ৳ টাকার কয়েন কালেকশন টিং শব্দ এবং ধামাস ক্র্যাশ সাউন্ড!
- **মজাদার ঢাকাইয়া কমেন্ট্রি ও এক্সিডেন্ট বুলেটিন**:
  - "এইটা কি দাদার রাস্তা পাইছেন নাকি?! এত জোরে চালান ক্যা?!"
  - ক্র্যাশ হলে কমিক নিউজপেপার কাটিং "দৈনিক দাদার রাস্তা বার্তা"!

## 🌐 গুগল ও ক্রোমে "দাদার রাস্তা" সার্চ দিলে গেমটি সবার উপরে আনার উপায় (Google SEO Ranking)

গেমের কোডে ইতিমধ্যে **Google Search Console** ও **Google Chrome**-এর জন্য সমস্ত অ্যাডভান্সড মেটাট্যাগ, বাংলা ও ইংরেজি কিওয়ার্ড এবং **Schema.org VideoGame Rich Snippet (JSON-LD)** যুক্ত করা হয়েছে।

### ধাপ ১: GitHub এ প্রজেক্ট আপলোড করুন
```bash
git init
git add .
git commit -m "Dadar Rasta 3D Game release"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/dadar-rasta.git
git push -u origin main
```

### ধাপ ২: Cloudflare Pages এ সম্পূর্ণ বিনামূল্যে ডিপ্লয় করুন
1. [Cloudflare Dashboard](https://dash.cloudflare.com) এ লগইন করুন।
2. **Workers & Pages** > **Create Application** > **Pages** ট্যাবে যান।
3. **Connect to Git** চাপ দিয়ে আপনার `dadar-rasta` রিপোজিটরি সিলেক্ট করুন।
4. বিল্ড সেটিংস দিন:
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
5. **Save and Deploy** চাপলে ৩০ সেকেন্ডে আপনার সাইট লাইভ হয়ে যাবে (যেমন: `https://dadar-rasta.pages.dev`)।

### ধাপ ৩: গুগল সার্চে ইনডেক্স করানো (Google Search Console)
1. [Google Search Console](https://search.google.com/search-console) এ যান।
2. আপনার লাইভ ওয়েবসাইটের লিংকটি (URL Prefix) দিয়ে ওনারশিপ ভেরিফাই করুন (Cloudflare থাকলে ১ ক্লিকে হয়ে যায়)।
3. সার্চ কনসোলের উপরে **URL Inspection** বারে আপনার ওয়েবসাইটের লিংক পেস্ট করে এন্টার দিন।
4. **"Request Indexing"** বাটনে ক্লিক করুন।
5. ব্যস! গুগল ক্রলার ১২ থেকে ২৪ ঘণ্টার মধ্যে সাইটটি ক্রল করবে। এরপর যে কেউ গুগল ক্রোম বা গুগল সার্চে **"দাদার রাস্তা"** (বা "Dadar Rasta") লিখে সার্চ দিলে আপনার গেমটি সবার উপরে র‍্যাংক করবে!
